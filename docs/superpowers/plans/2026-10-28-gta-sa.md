# GTA San Andreas (original PC release) auto splitter — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port tduva's `GTASA.asl` to a `games/gta-sa` WASM crate that behaves like the ASL, sharing gta-sa-de's settings machinery and split rules through a new `crates/gta-sa-common` crate.

**Architecture:** `crates/gta-sa-common` holds what both games run the same way: the settings tree (dropdowns synced with checkboxes) and its `asr` glue, `Pair`, the split-once list with cooldown, the pure split rules, and the shared name lists. gta-sa-de is refactored onto it with no behaviour change. `games/gta-sa` adds the ASL's tables (1.0 module-relative addresses), version detection, its own layout with the ASL's defaults, and an `asr`-free `Splitter` fed by plain `Values`, so the split logic is host-tested; `lib.rs` only reads memory and drives the timer.

**Tech Stack:** Rust (stable, `wasm32-unknown-unknown`), `asr` (git, pinned in `Cargo.lock`), `dlmalloc`, `cargo test-host`.

**Spec:** `docs/superpowers/specs/2026-10-28-gta-sa-design.md`. Source ASL: <https://github.com/tduva/LiveSplit-ASL/blob/master/GTASA.asl> (a copy for reference: `curl -sSLO https://raw.githubusercontent.com/tduva/LiveSplit-ASL/master/GTASA.asl` into a scratch directory). Line numbers below (`ASL:123`) refer to that file.

## Global Constraints

- Branch `feat/gta-sa`; every commit Conventional and signed (`git commit -S` is automatic if `commit.gpgsign` is set; check `git log --show-signature -1`). End every commit message with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Never push to `main`.
- Checks before every commit that touches Rust, all must pass:
  `cargo fmt --check`, `cargo clippy --release --locked -- -D warnings`, `cargo clippy --tests --locked --target x86_64-unknown-linux-gnu -- -D warnings`, `cargo test-host --locked`, `cargo build --release --locked`. (Drop `--locked` only for the one command that first updates `Cargo.lock` after a dependency change, then commit the lock file.)
- **Faithful port:** gta-sa behaves like the ASL. Suspected ASL bugs are kept as they are and listed for in-game testing, never fixed. The one exception: the split-once list is also cleared when the auto splitter resets the timer.
- **No gta-sa-de behaviour change:** same widgets (keys, labels, tooltips, defaults, order), same splits, same log text. Its existing tests pass unchanged except for `use` paths.
- Setting keys are the ASL's. Section dropdowns are keyed `{section}#section` as in gta-sa-de.
- gta-sa log prefix: `[GTASA Autosplitter]`. gta-sa-de's stays `[GTASA:DE Autosplitter]`.
- gta-sa tick rate 30 (`refreshRate = 30`): load guard 15 ticks (500 ms), split cooldown 75 ticks (2.5 s).
- gta-sa process names: `gta_sa.exe`, then `gta-sa.exe`. 32-bit process: pointer paths use `PointerSize::Bit32`.
- Logic that doesn't need the runtime lives in modules without `asr` calls; anything that logs goes through a `debug` fn that is a no-op under `cfg(test)` (asr's imports don't link on the host).

## Review Focus

1. **Failed reads look like no change.** At the main menu the player ped pointer is 0, so `pedStatus` can't be read; a failed read must keep the previous value, never become 0 and split a warp later. → `Pair::update(None)` test in Task 2, and `failed_read_does_not_split` in Task 5.
2. **Attaching mid-game splits nothing.** The first memory read must seed both `old` and `current`, so restarting LiveSplit during a run doesn't split everything already done. → `first_values_have_no_changes` in Task 5.
3. **Unknown version does nothing but keep settings in sync.** No start, split or reset; the module size and the six version values are logged once. → `detect` tests in Task 3; main-loop behaviour checked in review of Task 5.
4. **Reset then start in the same tick.** New Game while running: reset clears the split-once list, then start fires on the same values. → `new_game_while_running_resets_and_clears` in Task 5.
5. **Thread name edge cases.** A 10-byte buffer with no NUL, or garbage, never panics and only matches whole names. → `thread_name_trims_at_nul` and `start_mission_needs_exact_name` in Task 5.
